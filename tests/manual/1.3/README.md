# 地面碰撞回归

pnpm dev 后打开 localhost:5173，刷新触发 WASM 加载和测试立方体从 y=5 下落。物体应落到地面并停止，不能穿过或一直悬浮；没有键鼠控制。

等待落稳后读取开发控制台 ground.check，中心 y 约 0.5，速度为 0；physics.check 应为 60 个固定步、2 个刚体和 2 个碰撞体。

pnpm build → pnpm preview，打开 localhost:4173，重复刷新和落稳检查。生产版无 ground.check 开发诊断，以实际画面验收。WASM 初始加载可能短暂只显示背景，加载完成后应正常重绘并模拟。

无地面与地面范围外的负向对照通过真实 Rapier 集成测试验证：pnpm test。浏览器不加入额外测试按钮或移动机制。

验证动态页面时应显示并聚焦预览。隐藏的内置浏览器可能暂停 rAF，只保留 WASM 加载前的背景画面；不能把隐藏状态的截图当作碰撞或渲染失败。可见状态下 demand 仍出现过空画面，最终采用 always 渲染 + independent 固定步物理；不把渲染帧率用作物理 dt。

内置浏览器若导航后只有背景，重新隐藏/显示预览再检查。本次此路径恢复了可见场景；always 也不保证消除此呈现问题，尚需其他浏览器对照首次加载。
