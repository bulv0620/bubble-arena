# 1.5 键盘输入手动回归

1. pnpm dev 打开 http://localhost:5173/，点击场景获得焦点，左上角显示 WASD 输入四项全 0。
2. 按住 W+A，显示 W:1 A:1；松开 A，仅 A 回 0；松开 W，全部回 0。胶囊始终静止。
3. 按住 W 后切换应用/标签页，再松键并返回页面，确认全部回 0，不保持之前的按住状态；重新按 W 才再次变为 1。
4. Ctrl/Command+A 等快捷键不形成移动意图，Space 不属于此任务。开发控制台 input.check 只在状态变化时记录布尔值。
5. pnpm build / pnpm preview，http://localhost:4173/ 无诊断面板与输入日志，仍不移动。

编辑区路径暂由自动事件测试覆盖，因为当前场景没有文本输入框。内置浏览器导航若只显示背景，沿用既有呈现问题记录；不要把空背景当作视觉验证成功。

dev.png：浏览器实际发送 W+A 后松键的状态，角色原地；dev-logs.json：真实按下/组合/分别释放日志。持续按键、应用切换和手感等待用户试玩验收。
