# 1.11.1 顶墙起跳复测

2026-10-08。

1. 刷新 localhost:4173，落稳后 W 走到北墙，继续按 W 并按 Space。胶囊应正常离地，约 1.2m 跳高；不能穿墙。
2. W+A 顶住墙角后继续保持方向，按 Space；仍应正常离地。墙角由完整地图自动夹具连续 60 tick 验证。
3. 走上绿色 45° 坡，持续 D 加 Space：有短暂离坡，但满速向上跑时离坡间距小。松开 D 站稳再按 Space，离地感明显。30°/45° 满速上坡自动夹具确认起跳速度、额外法向间距约 33.72cm / 5.89cm。
4. 真正的顶棚仍阻止上升；页面没有顶棚，已有低顶测试夹具验证。
