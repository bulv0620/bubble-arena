# 2.1 第三人称跟随镜头试玩

2026-10-08，开发 localhost:5173 与生产 localhost:4173 实际核对。

1. 刷新：从角色后方右肩视角看白盒，胶囊中心略偏屏幕左侧。
2. 按 D 约 1.75 秒、松开：镜头随人物平移到右侧坡，人物大小和构图基本保持。开发验证使用两次 0.85 秒 D，中间松开；生产为连续约 1.75 秒。
3. Space 起跳：镜头跟随竖直位置，人物保持屏幕位置，墙/坡相对屏幕移动。
4. 松键停稳并刷新：新角色引用恢复正常跟随。按 WASD 可验证另外方向；鼠标旋转尚未实现。

开发：[出生](dev-start.png)、[移动上坡](dev-moved.png)、[起跳](dev-jump.png)、[实际日志](dev-logs.json)。日志筛选最终 25° 俯角加载 12:28:11 UTC 之后，包含目标/相机与 distance=4.5、fov=70，无 error。生产：[出生](preview-start.png)、[移动上坡](preview-moved.png)、[起跳](preview-jump.png)，error 查询为空。

4.5m 从肩部观察点测量，不是从胶囊中心测量。箱子或墙可能挡住角色；镜头避障是后续任务，目前不要把遮挡误认为跟随失效。角色移动和碰撞逻辑仍属阶段 1，跟随相机只读角色位置。
