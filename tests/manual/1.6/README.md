# 1.6 水平移动手动回归

1. pnpm dev 打开 http://localhost:5173/；或 pnpm build 后 pnpm preview，打开 http://localhost:4173/。开发页面额外显示键盘状态。
2. 按住 W/S/A/D，分别沿 −Z/+Z/−X/+X 移动；松键短暂减速后停止。固定镜头尚不跟随。
3. 刷新后按住 W 约 1 秒，橙色胶囊到灰墙前停下；继续 W 不应穿墙。
4. 保持 W，再按 D，胶囊应向右沿墙滑动；不要一直走出墙端再把绕墙当作穿墙。墙的 x 范围 [-3,5]、z 范围 [-3.25,-2.75]。
5. 刷新后走对角与直线，感受最高速度相同；按住移动切换应用后返回，不应保留旧按键。存在约 0.17 秒最大减速时间。
6. 蓝色动态立方体不是静态掩体，角色可穿过它；正式箱子在 1.7 添加。当前脚底离地 2cm，y 固定，无重力/跳跃/跌落死亡。
7. 查看开发 movement.check 的真实 position/desired/allowed；生产无输入和运动诊断日志。若导航只见背景，先点击/按键查看，既有内置浏览器呈现问题尚待定位。

dev.png / preview.png 为本任务实际页面，dev-logs.json 为真实事件与位移日志。自动测试覆盖连续 60/120 个真实 Rapier 物理步和墙滑；工具浏览器按键会快速松开，持续手感仍待用户验收。
