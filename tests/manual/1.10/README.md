# 1.10 斜坡与台阶试玩

2026-10-08，开发 localhost:5173 和生产 localhost:4173 实际核对。当前固定镜头，白盒地形：右侧绿色 45° 坡，前方蓝色 0.3m 台阶。

1. 刷新并落稳后按 D 约 1.8 秒，松开：角色应站在绿色坡上；不需要跳跃。
2. 按 A 约 0.45 秒，松开，走回坡底地面。
3. 按 S 约 1.15 秒，松开，走上蓝色台阶；不按 Space，胶囊脚底升高约 0.3m。
4. 坡上可按 Space 起跳，空中反复按键不能二段跳。30°、45.1°、55°、高台阶和低顶阻挡由自动夹具测试；页面只有 45° 坡与 0.3m 台阶。
