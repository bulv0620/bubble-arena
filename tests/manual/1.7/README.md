# 1.7 墙箱碰撞手动回归

1. pnpm dev 打开 http://localhost:5173/；或 pnpm build / pnpm preview，打开 http://localhost:4173/。
2. 确认两面相接灰墙、两个棕箱和橙色胶囊；不再出现蓝色下落演示体。
3. 刷新后按 W 靠近主墙，继续按住不应穿入；W+D 可沿墙滑动，绕过墙端属于正常绕行。
4. 刷新后 W+A 靠近左侧墙角，持续按住不应穿入两墙；改为 S+D 可脱离墙角。
5. 靠近棕箱四面，正面阻挡、斜向可沿边滑动；绕过箱角后可继续前进，不应出现箱体之外的隐藏阻挡。
6. 松键/切换应用后输入清空并减速停止。当前镜头固定，y 固定且脚底离地 2cm；Space 与重力尚未实现。
7. 开发控制台 physics.check 为 6 刚体/6 碰撞体、固定 dt≈1/60、地图哈希 fnv1a64:f100071d20585698；无 error，既有 Rapier warning 保留。

生产导航若只显示背景，重新展示预览后复核；这是既有待定位问题，不能把背景截图当作视觉通过证据。dev.png / preview.png 是实际正常场景截图；dev-logs.json 是此次加载的实际日志。四面接近、角落脱离与绕箱的连续 tick 已由真实 WASM 自动测试覆盖，手感仍需用户验收。
