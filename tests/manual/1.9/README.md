# 1.9 接地与再次起跳

2026-10-08，开发 localhost:5173 和生产 localhost:4173 实际核对。画面为工程白盒，固定相机。

1. 页面落稳后短按 Space：胶囊离地。
2. 空中反复按 Space：不会追加起跳。此连续行为已由真实 Rapier 固定步测试验证，建议人工试玩确认手感。
3. 落地后松开并再次按 Space：可再次跳跃。按住不松开应只跳一次。
4. WASD 靠墙并跳跃：墙面不提供二段跳资格。箱沿、支撑移除和传感器排除通过测试夹具验证；当前页面没有传送或移除箱体调试按钮。
