# 0.2 创建 React / TypeScript / Vite 最小页面

状态：accepted，阶段 0 工程验收。里程碑 M0。实现与验证见 ../reports/0.2.md。

## 唯一目标

在 apps/web 建立能本地启动、类型检查和生产构建的最小页面，显示 Bubble Arena 和“工程初始化”提示。

## 前置与阅读

0.1/0.7 工作区已 implemented。阅读 AGENTS.md、README、ARCHITECTURE；检查本机 Node/pnpm，首次安装核对 Vite/React/TypeScript 的 engines 与兼容关系，固定具体版本。

## 允许修改

apps/web/**、根 package.json 的命令、pnpm-lock.yaml、必要的 tsconfig、docs/reports/0.2.md、docs/STATUS.md、tasks.json。保留 apps/web/README 的职责说明。

## 本次不做

不安装 Three/R3F/Rapier/Colyseus，不建 Canvas、角色或大厅，不调用 Blender，不做正式视觉设计。

## 实现步骤

1. 创建 @bubble-arena/web package、index.html、src/main.tsx、src/App.tsx、最小样式和 Vite/TS 配置。
2. 固定 React、React DOM、Vite、React 插件、TypeScript 和 types 兼容版本，pnpm install 产生 lockfile。
3. web 提供 dev/typecheck/build/preview；根提供 pnpm dev、pnpm typecheck、pnpm build，明确 filter 到 web。不要添加没有实现的 test 空通过命令。
4. 启动浏览器检查页面及控制台，执行类型检查和生产构建，更新使用说明和任务报告。

## 验收

- pnpm install 可重复执行；pnpm dev 监听 localhost:5173，页面显示项目名称和当前阶段，刷新正常，无错误控制台。
- pnpm typecheck、pnpm build、pnpm check:workspace 成功；生产输出在 apps/web/dist。
- 报告列出实际依赖版本、浏览器查看结果、检查命令；未做的浏览器检查明确记录。
- 无超出目标的 3D/联网/模型逻辑。
