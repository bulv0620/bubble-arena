# 3.12.5 移动散布与取消普通武器右键效果

用户2026-10-09授权加入移动散布并去掉普通武器右键效果。前置3.12.4 implemented，当前只实现步枪，不进入新武器/阶段4。

范围：shared/game-core步枪散布，web player/weapons/camera/input/HUD装配及相关测试文档。静止2°、实际水平速度≥0.15m/s时乘1.5→3°；读取物理步碰撞允许位移而不是按键猜测，碰墙不动不扩大，滑墙/减速期间仍有实际移动则扩大。有效开火时捕获该步散布，不额外改变后坐力/伤害/射程。移动准星64→80px，停稳收回。步枪右键不收束、不减速、不缩准星、不切镜头；当前移动速度统一5m/s。保留只在锁定失败浏览器中用于区分拖镜头/射击的右键+左键后备输入，不产生武器瞄准效果。通用AimInput暂留供后续狙击开镜，当前不实现狙击。

验收：实际移动/停止/墙阻与散布角边界、随机射线锥界限、配置/异常/订阅释放、普通武器右键模式不变化和后备输入回归；pnpm check通过及浏览器验证。报告docs/reports/3.12.5.md，更新状态索引，implemented后停止待人工验收。

结果：implemented，待人工手感/视觉验收。详见 [报告](../reports/3.12.5.md)。
