# 3.12.11 改善首发精度、连射扩散与后坐力

用户明确授权查询典型FPS逻辑并实现更好的步枪效果，前置3.12.10 implemented。

参考官方CS Second Shot、VALORANT Phantom vs Vandal/3.0、Destiny开发者后坐力说明；实现本项目初值，不冒称复刻原游戏内部算法。静止基础0.2°，移动0.9°/空中1.5°不叠加；随机偏向中心。接受射击后增加0.18°bloom，上限1.4°；0.18s停火延迟后2.8°/s恢复，首发使用加热前散布。核心固定步控制bloom，不由UI计时；实际散布和动态准星同源，提示尺寸36～112px仍非精确屏幕弹道边界。后坐力每发1.2°、上限6°，停火0.16s后9/s回落，射击期间可积累，当前镜头/枪口安全规则保留。

范围：shared/game-core/weapons/HUD/camera装配及相关测试/spec/report。保留无限备弹、自动换弹、跳跃扩散与重置三靶；不引入狙击/联机/正式Blender资产或新阶段。验证首发、连续接受/拒绝射击、恢复/重置、随机分布界限、后坐力帧率/释放/可压枪及实机对照，完整检查后报告并停止。

结果：implemented，待人工射击手感验收。见 [报告](../reports/3.12.11.md) 和 [当前规则](../spec/RIFLE_GUNPLAY.md)。
