# Splash Club：卡通水枪 UI（4.12）

2026-10-15，用户授权本阶段UI重设计。4.11玩法已实现，4.12仅视觉扩展，待人工验收。

## 参考与取舍

参考 [泡泡战士实机与Nexon介绍截图（Inven存档）](https://www.inven.co.kr/webzine/news/?news=16740)、[泡泡战士实机截图](https://m.ruliweb.com/game/1085/read/3665912) 的红蓝比分、生命弹药与卡通表现，以及 [Splatoon 3 官方](https://www.nintendo.com/us/store/products/splatoon-3-switch/) 的鲜明配色和有机水花装饰。仅参考视觉组织方式，未下载或复用这些游戏的角色、商标或贴图。没有引入雷达自动命中等玩法。

## 视觉合同

水蓝/青绿为基础，珊瑚红与蓝区分队伍，明黄用于开始/赛前/计时，青柠用于返回/生命；深蓝粗描边、白色内高光和向下硬阴影构成立体玩具感。字体使用系统圆体优先、中文系统字体回退，不依赖外部字体服务。

- 顶部红蓝比分翼板围绕计时牌，比分带队名和YOU/AI标识；赛前准备单独使用水花装饰卡，开始后消失。
- 生命左下、弹药右下，强调大数值/实体弹匣格，1/2槽位用黄色突出；步枪/霰弹/狙击/泡泡四种原生SVG轮廓区分。小地图继续渲染shared真实几何与物理遥测。
- 设置为带原创泡泡吉祥物的水蓝页头、操作装备/场地练习双栏及底部操作区；窄屏单栏滚动。Esc和可点击设置入口打开，返回请求锁定沿用原逻辑。禁用控件不进入焦点循环。
- 结算为泡泡星章、胜队色标题、红蓝最终比分和真实统计；开始/返回/重开为立体大按钮。结果只由真实比赛状态驱动。
- 倒地/淘汰/救援/保护保持独立文字与颜色，不能只靠颜色识别。焦点使用橙色外框；低动态偏好取消新增按钮过渡，原浮字降级继续保留。

装饰不参与射线/碰撞；头顶血条的108/76px投影尺寸及距离缩放、人物锚点、准星与冷却/装填环的中心和尺寸不变。UI不拥有物理tick或定时器。比赛时间、AI、伤害、地图/出生哈希均未修改。

## 资源与生成

使用imagegen技能和内置image_gen生成两张原创透明PNG，保留alpha；分别用于设置/结算/生命头像和赛前水花。实际文件见 [资源清单](../../assets/manifest.json)，完整提示词、工具模式与日期见 [生成记录](../../assets-source/ui/generation-v1.json)。总量约2.7MiB，按浏览器同URL缓存，不为每个HUD复制图像。无新增依赖、无CLI/API密钥或付费外部平台配置。素材原始输出另存于Codex generated_images，项目只引用仓库内public/ui文件。

当前是2D UI插画，未替代人物、枪械或正式地图模型；Blender MCP B.1状态保持。后续人物正式资产可替换左下头像，不将此装饰吉祥物当作3D人物外观。

## 断点与验收

1000px以下收起品牌副标题，将操作提示上移；800px压缩侧边HUD；600px以下进一步压缩并将设置改成单栏；短窗口允许弹窗滚动。验收范围为桌面1280×800、800×600、小窗390×844及默认浏览器宽度；以本轮实际截图/日志为准，不声称移动触屏操作已实现。

## 4.12 本轮视觉深化（v2）

保留前述色彩/玩法边界，赛前由表单卡改为蓝色波点海报标题、红蓝对战标签、原创双色水泡徽章及三张赛制按钮。标准/15秒速体验/一分决胜仍使用原MATCH_CONFIG。装饰图仅存在于waiting和finished，playing的准星周围无新增遮挡。结算沿用真实胜队与统计，以同一徽章和蓝色页头统一。

设置主武器由select改为三个原生button（aria-pressed、fieldset disabled），显示共享WEAPON_HANDLING对应名称/重量/速度及共享WeaponIcon轮廓，Enter/Space可选，禁用时不得切枪。设置页加入现有操作小抄，不增加任何控制方式。生命左侧青色外壳、弹药青绿整体底色、地图黄色页头加强区分；文字启用字体粗体合成，解决部分系统字体在font-synthesis:none下标题显细。

新增 [bubble-duel-v2.png](../../apps/web/public/ui/bubble-duel-v2.png)，内置image_gen生成，1536×1024 RGBA，1,935,877 bytes。透明通道实测777,563个全透明像素，其余含半透明水泡/光晕；完整提示词在 [generation-v2.json](../../assets-source/ui/generation-v2.json)。旧资源和生成记录保留，v1水花暂不用于赛前。新徽章用于赛前/结算，原吉祥物继续用于生命头像/设置。

小窗弹窗允许纵向滚动，短横屏赛前高度最多视口减145px；390×844赛前自272px开始，设置单栏。仅适配显示，尚无触屏移动或射击。最新实拍见 [本轮证据](../reports/evidence/4.12/refinement/production-waiting.png)。

## 4.16 Esc设置精简覆盖

设置改为420px上限的紧凑单栏：仅游戏设置标题、鼠标速度滑杆/当前倍率、重开本局、返回游戏与房间入口。移除英文标语、吉祥物、说明/操作小抄、模式说明、重开/锁鼠标提示及训练生命/计分/救援调试面板。房间继续负责模式/赛制选择，训练核心与测试组件保留。鼠标释放/返回请求锁定、设置持久化、焦点循环沿用既有行为，短窗允许滚动。此节覆盖4.12设置双栏与提示文案要求。

4.16.1：鼠标倍率范围0.05～3，步长0.01，默认1；沿用原存储键，兼容已保存倍率。最低档与0.06低速档均作用于水平/垂直镜头输入。
