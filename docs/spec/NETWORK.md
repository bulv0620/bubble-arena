# 网络、会话与命中协议

## 正式协议意图

共享 Schema 严格拒绝未知敏感字段；协议 version 与地图 hash 握手不一致则拒绝入局。

Input { protocolVersion, seq, clientTick, moveX, moveY, jumpPressed, aiming, aimYaw, aimPitch, fireHeld, firePressed, reloadPressed, interactHeld, targetPlayerId? }
Snapshot { serverTick, ackSeqByPlayer, players, matchState, scores, remainingTicks }
Event { eventId, matchId, lifeId?, tick, type, actorId, targetId?, weaponId?, position?, shotId? }

move 范围 [-1,1] 并归一化，pitch 受配置限制，所有浮点必须有限。客户端不发送自由 dt，不按客户端墙钟推进模拟；每 tick 只消费允许时间内的输入。边沿操作用序号去重，缺失输入保持移动最多 100ms 后归零，fire/interaction 遇连接失效立即归零。

初值模拟 60Hz、输入发送 30Hz（携带自上次发送以来的 60Hz 输入样本）、快照 20Hz。每消息最多 8 样本/4KiB，输入消息最多 60/s，累计突发上限 120/s；逐 tick 去重/窗口校验，旧序号和超前 >120 tick 丢弃。不能用消息数量增加移动距离或射速。所有时间由 server tick 决定。

## 预测和反馈

客户端保留最多 2 秒未确认输入，快照回到权威位置后重放剩余输入。较小修正只平滑视觉偏移，物理立即按权威结果；大偏差 >2m 或复活直接重定位。远端插值初始缓冲 100ms，最多外推 100ms，超时冻结而非无限前进。

事件以 matchId + eventId 去重，音效不因重放输入重复触发。弹药/伤害/计分最终由快照及权威事件确认。比赛配置、地图碰撞版本和出生点在开局前同步。

## 命中和延迟补偿

M1 先采用服务器当前 tick 命中作为可测基线；V1 网络阶段增加有限历史胶囊回溯，窗口最多 150ms。客户端开火序号通过时钟偏移估计映射服务端 tick，并由服务器限制，不能直接接受任意历史时间。

hitscan 在开火时权威位置估算镜头/准星方向，枪口→瞄准点二次检测，枪口近墙先碰墙。瞄准状态和枪口挂点用共享逻辑推导，不信任客户端传来的枪口位置。回溯只查询历史玩家命中体，静态墙保持遮挡；不修改实际物理世界。泡泡投射物不回溯，按当前服务器 tick 飞行。

若回溯验证未通过，发布只能标为受限低延迟测试版，不能宣称满足 V1 网络门槛。

## 会话与重连

游客 playerId + 服务端重连凭据存 sessionStorage；刷新同标签页可恢复，关闭标签页或新窗口创建新游客。凭据绑定房间和玩家，不以昵称识别身份；不永久保存战绩。

意外断线保留席位 15s，角色留在场内、输入归零且可受击；自然规则继续运行。15s 内允许原玩家重连到原生命状态，无重生奖励。主动退出立即释放席位；关闭时主动通知只能优化，最终仍用超时清理。

任一队没有已连接玩家时启动 15s 缺席倒计时；期间仍正常战斗，计分/时间结束优先。窗口到期，仅一队缺席则该队判负；双方都缺席则 abort，不记胜负。成员超时离开后不允许新玩家中途补位。

房主离开转给入房最早的已连接成员；暂时无人连接时保留至宽限到期，再解散空房。重连不自动夺回房主身份。服务进程重启不恢复对局，客户端提示中断并回大厅；首版不做多实例跨服迁移。
