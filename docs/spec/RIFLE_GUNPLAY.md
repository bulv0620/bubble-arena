# 当前步枪射击手感（3.12.11）

用户反馈后坐力不明显、首发随机偏差大，授权调研其他FPS并调整。本方案是Bubble Arena的试玩初值，未复制其他游戏源代码/精确数值，仍为本地训练原型。

## 官方资料与采用的思路

- [CS:GO Second Shot](https://blog.counter-strike.net/second-shot/)：准确度随连射积累，短点射与长连射可有不同的恢复速度，鼓励点射/短连射。采用小首发误差、有限累积bloom和停火恢复。
- [VALORANT开发者：Phantom vs Vandal](https://playvalorant.com/en-us/news/dev/valorant-data-drop-phantom-vs-vandal/)：首发/第二发、弹道散布和后坐力恢复都是不同的射击控制因素。[3.0更新](https://playvalorant.com/en-us/news/game-updates/valorant-patch-notes-3-0/)说明走动/跑动准确度惩罚，强调停稳射击。采用移动与空中惩罚，不照搬战术FPS的大幅移动惩罚。
- [Bungie开发者：2023-09-21](https://www.bungie.net/7/en/News/article/twid_09_21_2023)：可辨认后坐力方向与每发准确度误差是两回事，停火使武器恢复。采用可控垂直镜头上抬与单独随机误差；当前未做它的横向固定弹道图案。此页open异常，参考搜索返回的官方正文摘录，不声称看完其演示视频。

## 当前参数（圆锥半角）

| 行为 | 基础散布 | 作用 |
| --- | --- | --- |
| 静止/已恢复 | 0.2° | 首发最大偏角比旧2°缩小90%，不是绝对零误差 |
| 水平速度≥0.15m/s | 0.9° | 仍可移动射击，但停稳更准 |
| 起跳/未着地 | 1.5° | 最高点/下落保持，跑跳选空中值不相乘 |
| 每次接受射击后 | +0.18° | 逐发开锥，首发用加热前角度 |
| bloom上限 | +1.4° | 不无限扩大，静止最大1.6°、移动2.3°、空中2.9° |
| 停火恢复 | 等待约0.18s后2.8°/s | 小bloom较快回满，最大bloom约0.7s回满，60Hz向上取整 |

每发使用两个本地随机样本；角向方向均匀，锥径样本先平方，因此落点更偏向中心，但仍可能落到边缘。大约50%样本在半径的一半以内，而原均匀圆锥约25%；这是本项目设计，不是声称某游戏的精确分布。核心保留通用uniform spreadDirection，当前步枪明确调用rifleSpreadDirection。

后坐力单发1.2°，累计上限6°；每次接受射击后0.16s内不回落，随后9/s指数回落。8/s正常连射能积累至上限，鼠标基础pitch仍独立，可向下移动鼠标补偿；停火镜头回到基础pitch。首发射线使用kick前目标点，本发不会被自己的镜头kick偏移。没有额外水平随机镜头抖动。

准星读取同一实际散布角，36px冷态、移动56px、空中72px，连射逐渐张开，恢复逐渐收回，上限112px。其最小可读尺寸/比例是UI表现，不是枪口视差下严格的屏幕落点边界；真实弹道仍是枪口3D锥形射线，墙体/枪口安全段优先。

## 生命周期与边界

RifleAccuracy只按固定模拟步推进，每步只接收已接受射击布尔值；拒绝/空匣/换弹射击不加bloom，释放输入不瞬间清除bloom，换弹等待自然恢复。RifleMotion仅在角度变化时发布订阅，不由HUD管理物理tick。重置训练清空bloom/后坐力，旧订阅释放；无限备弹/自动换弹/伤害/射程保持。后续联机时核心与随机样本仍须由服务端权威执行。
