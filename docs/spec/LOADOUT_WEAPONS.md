# 四武器装备与训练规则（4.14 / D24）

2026-10-15 用户 4.14 覆盖此前两槽规则：步枪、霰弹、狙击、泡泡四枪全部携带，固定 1/2/3/4 槽位，房间与设置不再选择主枪。支持数字键、画布滚轮前后循环和武器栏按钮；实际装备仍由固定模拟步消费意图。当前为单机训练/AI 对抗，正式模型与联机仍待其任务。

步枪沿用现行散布/bloom/后坐力及20～60m降至50%伤害。霰弹静止6°，移动×1.2/空中×1.5；八独立均匀锥形弹丸，逐丸命中头/身与距离，5～25m线性降至20%，每目标一次开火合并实际伤害/浮字，最大近身112/全头168，近距八颗身体全中可清空100HP，少一颗为98伤害。狙击腰射5°，移动×1.5/空中×2；开镜静止0°、移动0.15°、空中0.75°，FOV24°并显示镜圈准星；开镜隐藏自身占位外形与头顶自身血条，边缘HUD保留，退出恢复。狙击所有有效射程内无伤害衰减，基础头160足以清空当前100HP训练靶；正式角色未来依其最大HP/生命状态处理，不提前实现淘汰。

泡泡按用户补充确认沿用此前方案：半径0.15m、速度20m/s、寿命2s、无重力/反弹，固定步扫掠避免穿墙/靶。首次碰撞爆开，半径2m，对范围内且墙无遮挡的靶子造成25伤害/2s减速50%，不套头倍率或距离衰减。训练靶静止，仅显示减速状态并保留核心倍率/时长接口；当前没有可受该效果的敌方移动角色。到期无伤害消失；飞行池有界，切武器不取消已发射泡泡，重置/卸载清空。

## 装备、输入与生命周期

共享 WEAPON_IDS 顺序是唯一槽位顺序，weaponSlot/weaponForSlot 校验输入。每枪已有弹药保留，首次满弹；本局重开保留当前持枪、恢复四枪弹药并清空靶/镜头/事件/反馈，不重挂 Canvas；新一局默认步枪。鼠标速度保留，不保存房间选枪或跨局持枪偏好。

数字 1–4（含数字小键盘）与可点击武器栏只产生绝对槽位意图，画布滚轮收集相对循环步数，物理 tick 合并消费；绝对意图覆盖更早滚轮，之后滚轮在该槽位上累加，循环偏移有界。滚轮监听仅挂画布且可释放，不拦设置/房间滚动或 Ctrl/Alt/Meta 操作；编辑控件/设置/失焦/隐藏屏蔽和清除。同槽重复无副作用；切换取消原枪换弹（不扣备弹）、空匣切回时自动重新开始装填，非空匣中断后须重新按R；只清空开火/换弹/瞄准和镜头后坐力，保留按住的移动方向和已排队跳跃，不重建移动控制器；不取消已射泡泡、不重置原枪冷却。武器冷却在收起时继续按物理tick推进，不靠切枪绕过。新枪必须重新按左键，半自动不会因一直按住或切换重复开火。所有枪共用全局射击序号，多个弹丸按目标聚合、一个泡泡每目标结算一次。

普通枪右键无收束/移速/镜头变化。狙击右键点击切换开/关镜，松开右键不关闭；每次接受射击后自动关镜，击发冷却与装填期间拒绝开镜，读条结束后须重新点击，不排队或自动重开。切换/Esc/失焦/失锁仍关闭。内置锁定失败仍使用明确后备输入，后备右键+左键仅作为输入路径。
