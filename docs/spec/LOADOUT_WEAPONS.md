# 双武器训练规则（3.14.1～3.14.4）

2026-10-09用户授权整批，覆盖旧一人一枪/局内不切枪及新枪后置限制：主武器三选一（步枪/霰弹/狙击），副武器固定泡泡，数字1/2切换。仅本地训练玩法；正式模型/联机/玩家生命状态待其任务。

速度=6−重量等级×0.5（m/s），这些等级不是现实kg。仅当前持枪决定速度，不把固定副武器重量叠加。狙击开镜移速×0.7=2.8m/s；保留加速、减速、空中控制与起跳规则。训练各武器无限备弹/空匣自动换弹，泡泡少发指每弹匣4发，非整局只能4发。

步枪沿用现行散布/bloom/后坐力及20～60m降至50%伤害。霰弹静止6°，移动×1.2/空中×1.5；八独立均匀锥形弹丸，逐丸命中头/身与距离，5～25m线性降至20%，每目标一次开火合并实际伤害/浮字，最大近身64/全头96。狙击腰射5°，移动×1.5/空中×2；开镜静止0°、移动0.15°、空中0.75°，FOV24°并显示镜圈准星；开镜隐藏自身占位外形与头顶自身血条，边缘HUD保留，退出恢复。狙击所有有效射程内无伤害衰减，基础头160足以清空当前100HP训练靶；正式角色未来依其最大HP/生命状态处理，不提前实现淘汰。

泡泡按用户补充确认沿用此前方案：半径0.15m、速度20m/s、寿命2s、无重力/反弹，固定步扫掠避免穿墙/靶。首次碰撞爆开，半径2m，对范围内且墙无遮挡的靶子造成25伤害/2s减速50%，不套头倍率或距离衰减。训练靶静止，仅显示减速状态并保留核心倍率/时长接口；当前没有可受该效果的敌方移动角色。到期无伤害消失；飞行池有界，切武器不取消已发射泡泡，重置/卸载清空。

## 装备、输入与生命周期

设置主武器选择立即切到主槽；每枪已有弹药保留，首次该枪满弹。设置选择本轮会话保留，重置恢复已选主枪/所有弹药/靶/镜头/反馈并回主槽，不重挂Canvas；鼠标速度保留。主枪选择不写入localStorage，以免跨版本污染。

数字1/2只产生槽位意图，物理tick消费；编辑控件/设置/失焦/隐藏屏蔽和清除。同槽重复无副作用；切换取消原枪换弹（不扣备弹）、空匣切回时自动重新开始装填，非空匣中断后须重新按R；清空开火/换弹/瞄准和镜头后坐力，不取消已射泡泡、不重置原枪冷却。武器冷却在收起时继续按物理tick推进，不靠切枪绕过。新枪必须重新按左键，半自动不会因一直按住或切换重复开火。所有枪共用全局射击序号，多个弹丸按目标聚合、一个泡泡每目标结算一次。

普通枪右键无收束/移速/镜头变化。狙击右键持按开镜，松开/切换/Esc/失焦/失锁恢复。内置锁定失败仍使用明确后备输入，后备右键+左键仅作为输入路径。
