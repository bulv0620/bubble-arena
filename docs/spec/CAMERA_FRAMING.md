# 泡泡战士式跟随构图基线（4.18.6.1）

2026-10-16。用户要求非常接近泡泡战士视角感。本版覆盖4.18.6近肩基线；数值是本项目按实机画面估算的设计参数，不是原作官方相机/身高数据。

## 参考与目标

实际观察[Ruliweb玩家实机截图](https://m.ruliweb.com/game/1085/read/3665912)及[ThisIsGame实机截图](https://file.thisisgame.com/upload/nboard/2009/01/23/20090123141305_3263.jpg)：大头、短身，人物位于下半屏，略偏左但靠近中央；动作、俯仰和画幅影响人物占比。参考只用于比例及构图，不复制人物/模型/贴图。

默认8°俯角、65°垂直FOV、1280×720、无遮挡站立；屏幕坐标从左上0%到右下100%。轴线投影不同于球形轮廓边缘。

## 同源形体与镜头

- PLAYER_CONFIG总高1.8→1.4m（降低约22%），半径仍0.35m；胶囊半高自动0.55→0.35m。BLOCK_AVATAR_CONFIG同源推导：头部直径0.7m，占总高50%，身体0.7m。运动、头身视觉/传感器/AI射线统一，无仅缩模型的隐藏大碰撞箱。出生Y/版本哈希、靶子高度、头顶条随配置变化，地图实体不改。
- CAMERA_CONFIG跟随仍2.6m，右肩0.9→0.5m，观察点相对胶囊中心0.8→0.95m，垂直FOV70→65°，初始8°不变。普通/右键基础相机相同，狙击仍24°；相机不写物理位置。
- 枪械socket.y从固定0.2m改为共享头身交界肩线，当前0m；实际枪口中心相对胶囊中心+0.15m。随矮身材下降，不抬枪凑准星；枪口安全段、视觉与命中同源，武器自身尺寸及重量/弹数不改。
- 人物/枪械只保护26px准星中心及近裁剪面，允许外围散布圈擦过人物上缘。自身头顶条单独避让完整散布/进度环，相交时仅临时隐藏该条、恢复后重新显示，不再因血条触圈隐藏整个人物。标签始终保留头顶世界锚点；左下HP仍持续显示。
