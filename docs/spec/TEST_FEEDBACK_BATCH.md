## 实施取值

倒地持续20秒沿用；隐藏耐久300，超时在当前位置恢复50HP并沿用1秒救起保护，不产生淘汰积分；实际淘汰仍基地5秒复活。E为上下文交互：敌方困泡按下踢爆，友方困泡按住2秒救援，距离2m且地图视线畅通，目标/状态/松键/伤害变化会中断；AI也受同样事实约束。竞态按既有固定tick顺序统一结算，结束后冻结。

房间机器人默认准备；房主无需准备，只有开始游戏按钮，当前双方至少一人即可开始。房主换位和成员增减后直接重算开局条件，未来仅非房主真人需要准备。仅点空位中央换位，已占位置不可换入，不交换机器人，原席变空；右上独立加/移除AI。只显示当前本机真人，房主离开到大厅后没有其他真人，立即解散；游戏回房不算离开房间。

Shift采用按住奔跑，只有正常生命/非救援且实际移动才能奔跑，优先退出开镜并禁止接受射击；枪重仍影响速度。跳跃按起跳实际水平速度取连续有界倍率，静止仍可正常起跳。具体参数纳入共享配置并验证，不通过移除枪口安全射线来修视差。

团队视野使用本地权威位置、朝向和地图LOS；地图始终显示队友，敌人仅在任一正常/倒地队友当前视域中显示，不泄漏真实不可见敌人位置。Tab只管理显示意图，不夺焦点或阻止物理/射击。浮字生命周期由已有物理tick消费，页面隐藏不会延长或重播。
