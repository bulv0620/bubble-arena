## 4.18 当前交互与可见性

友方蓝、自身绿、敌方红；困泡只显示名字/剩余时间，没有耐久条或补伤浮字。浮字由物理tick按1150ms淘汰，出视域/被地图挡住清队列，回视域只接收新伤害。击倒到期恢复不产生淘汰事件。
