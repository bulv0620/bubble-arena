## V1 任务集合差异

V1 不执行 7.12.1～7.12.3 竞技场和 9.3 八人测试；7.14 的“全地图”指已启用小镇/海滨，9.9/9.10 使用 2v2。7.9 只做房间武器选择与同步，不做局内换枪。9.2 是 5.17 的强化回归。阶段验收仅针对本里程碑必需任务，不因后置项目永远卡住。

任务 9.6 增加历史命中回溯和伪造时间校验（拆为 9.6.1/9.6.2，原 9.6 保留为综合网络验收）。只有两子任务通过后 V1 可宣称完成网络门槛。

## 阶段退出记录

在 docs/reports/stage-<N>.md 记录：任务集合与状态、完整回归命令、真人试玩结论、未解决缺陷、Git commit。核心玩法/视觉标 accepted 前需用户实际验收；阶段退出时必须有可回退提交。阶段 0 已记录在 docs/reports/stage-0.md，基线标识 stage-0-baseline；后续阶段逐一记录。
