# 任务 2.4.1 镜头障碍物检测

2026-10-08，implemented。本次仅实现检测，不改变镜头；前置 2.3 implemented，阶段 0/1 accepted。阶段 2 尚未关闭。

## 实现与文件

- packages/shared/src/camera.ts：obstacleRadius=0.2m、obstacleClearance=0.05m，单处参数定义；现有角度/距离保持。
- apps/web/src/camera/cameraFollowPose.ts：抽取 cameraFocus，与理想相机和扫描共用同一肩部观察点，避免双份公式漂移。
- camera/cameraObstacleProbe.ts：Rapier 0.19.2 World.castShape，以 Ball 扫描肩部观察点至理想相机。单位方向使 time_of_impact 等于球心行进米数；targetDistance=clearance，stopAtPenetration=true。命中距离已包含球半径/安全余量，不是中心射线表面距离；下步不可再重复扣同一余量。
- 复用现有地图查询兼容分组 COLLISION_GROUPS.player，排除动态/运动学刚体/传感器，返回最近兼容静态碰撞体 handle（Rapier 不透明句柄，不能当普通数组下标）、命中距离和段长；无命中为 clear，非有限/零长或非法结果为 invalid。起点在障碍内返回 0，不声称已有脱困处理。
- Ball 仅是复用 JS 形状描述，没有向 world 注册碰撞体/刚体、没有持久 WASM 查询对象，无新增释放责任。查询不 step、不写物理/镜头，不引入 React/DOM 到 shared 或 game-core。
- FollowCamera.tsx：从现有 Physics 上下文取 world，每渲染帧更新理想镜头后只读扫描；开发每 120 帧在 [camera.check] 增加 obstruction、probeRadius，生产仍检测但无诊断日志。无额外监听器、定时器或 React 每帧状态。
- cameraObstacleProbe.test.ts：6 个真实 WASM 世界行为测试，覆盖最近墙/解析距离、球擦边射线漏检、无障碍/段外/非法输入、起点重叠/地面、分组和对象过滤、重复查询不改变相机/目标/刚体与实体数。
- README、模块边界、共享参数说明、任务卡/注册表/索引、STATUS、本报告和 tests/manual/2.4.1 证据同步。没有新依赖、地图或玩法变化。
