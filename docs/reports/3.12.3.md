# 3.12.3 头顶血条、游戏HUD与逐次伤害浮字

2026-10-09，implemented，待人工视觉/手感验收。阶段3共15项implemented，未关闭，未进入阶段4。

参考：用户授权搜索泡泡战士实机。检索并浏览 [夜猫籽2018-12-29实机试玩](https://www.bilibili.com/video/BV1Kt411k74k/)，实际视频画面可见边缘信息布局、蓝色卡通界面及中央战斗留白。本次借鉴布局与视觉方向，界面用代码独立制作，无游戏贴图/视频资源下载或挪用；不宣称浮字规则来自该游戏内部实现。

实现：左下生命面板、右下武器剪影/大号弹药/30格弹匣条与装填状态；顶中显示真实训练命中和清空数，右上射击模式，底部精简操作说明。生产隐藏开火意图/键盘调试，开发收进折叠栏。未加入虚构比赛分数、时间或未实现玩法。

玩家与三靶头顶共用Html投影血条，随所属3D角色定位、面朝屏幕、无输入拦截；自己青色、靶子珊瑚色，靶子≤25%变为低血色、归零显示已清空。训练靶遮挡使用Drei occlude；玩家保留自身标识可见。真实HP来自现有规则，自己的100HP仍是当前无敌人攻击的初始化状态。

每次LocalTrainingTarget.receiveHit接受后，把实际lastDamage和shot sequence送入独立DamageNumbers队列，再通知HUD。命中不能靠React合并后的总次数推算，因此连续物理步不会丢事件；拒绝/重复/归零后命中不添加数字。随机偏移X±46px、Y±22px，受击目标附近独立上浮52px，寿命1150ms，每靶最多12条，容量满丢最旧。冻结稳定快照，animationEnd只删除对应ID，组件卸载清空并解除订阅，清空后仍拒绝旧ID；无计时器、不管理物理tick。减少动态效果偏好下改为原地淡出且仍清理。离开视野/遮挡可能使浏览器取消动画，队列容量限制仍有效，重现时动画结束或卸载清理；未宣称后台精准计时。

文件：HUD/OverheadHealth、gameHud.css、AmmoHint、HealthHint、TrainingTargetHint；effects/DamageNumbers及测试；LocalTrainingTarget、TrainingTarget、CapsulePlayer、BasicScene；AimHint、PointerLockHint；spec/状态/索引/本报告。地图、碰撞、射击、移动、伤害数值和正式模型未改，无依赖安装。
