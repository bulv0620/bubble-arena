# 4.14.1 泡泡枪 HUD 裁切修复

状态：implemented，待人工视觉验收。2026-10-15。未Git提交/推送。

## 原因与修复

用户截图中，泡泡枪下方露出一小块圆弧。HUD显示整张三视图的顶部侧视图，但统一裁切保留原图43%（440px），泡泡枪俯视图从第404px已开始，导致下一视图露出。读取原图透明度确认：侧视枪柄到398px，399～403px为视图间隔。

在 apps/web/src/HUD/combatHud.css 新增泡泡枪专属 clip-path: inset(0 0 60.8% 0)，保留39.2%即约401px，落在间隔内。此比例随图片缩放生效，展开、收起和各响应尺寸共用；保留完整侧视枪柄。不改原始三视图或游戏规则，不新增依赖。
