# 4.19 人物与木箱子弹穿透

日期：2026-10-17。状态：implemented，待人工玩法/平衡验收。用户要求狙击穿透损失最小，其次步枪、霰弹；本轮只扩展单机战斗，未进入联网或正式建模阶段。

## 实现

- packages/shared/src/weaponPenetration.ts：不可变共享配置和严格数据字段校验。狙击/步枪/霰弹每穿一人保留85%/65%/40%，每穿一箱保留75%/50%/25%；最多穿出3/2/1人、2/1/1箱。当前被击中的人物先受伤，然后才消耗穿出预算。连续相乘、预算分别计数。
- packages/game-core/src/bulletPenetration.ts、weaponDamage.ts：与引擎无关的按序结算，头身同人去重，1mm地图优先，射程及非法输入边界；距离/部位/穿透后只取整一次。无React、DOM、物理tick或网络传输依赖。
- apps/web/src/weapons/ballisticRay.ts、TrainingTargets.ts：收集完整枪口射程的真实Rapier地图与注册sensor交点；逐丸汇总，每目标一次受伤和浮字，已消费射击拒绝重放。准星预选/枪口安全段仍保留原遮挡逻辑。保护拒绝扣血仍消耗实体穿透，停用/注销目标不拦截。
- apps/web/src/player/arenaCombatRay.ts、arenaBotCombat.ts、ArenaOpponent.tsx：AI同源头/身/困泡体积与穿透规则，逐受伤者来源归属，保留友军免伤和可见目标索敌，不增加隔墙索敌。
- shared的arena.ts/whitebox.ts与maps/ArenaMap.tsx、WhiteboxMap.tsx：显式木箱材质传入固定刚体，竞技场仅西侧两大箱可穿；正面交叉木条提示。训练两箱也可穿。材质参与地图版本哈希，竞技场schema2、白盒schema3（fnv1a64:eec4606e04cf6656），出生版本同步派生。物理尺寸/视线/运动碰撞不变。
- effects/ShotFeedback.ts、ShotEffects.tsx：每丸继续至真正停止点/射程终点；真实穿透交点140ms短闪。每丸最多8落点、射手64个固定落点网格、16条曳光；复制冻结、过期/释放和射线排除沿用。没有永久弹孔或新模型。
- 规格、4.19任务卡、任务索引、README、STATUS及共享包说明同步。

详细比例/近身伤害示例及人工步骤见[穿透规格](../spec/BULLET_PENETRATION.md)。木箱损耗按完整物体固定收取一次，当前不按厚度计量、不破坏箱体；泡泡仍首次碰撞爆开，不增加穿透。
