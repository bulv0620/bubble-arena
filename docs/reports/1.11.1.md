# 任务 1.11.1 试玩问题修复报告

2026-10-08，implemented，待用户复测。用户反馈靠墙方向键+跳跃难以起跳，以及上坡跳跃像加速；本任务修复第一项并核验第二项，未进入阶段 2。

## 结论与原因

靠墙属于缺陷。旧 VerticalMovement.resolve 只要向上允许位移比期望位移少 0.00001m，就清零速度；墙侧接触的微小法线修正也会触发这一条件。新增真实墙面/墙角持续输入回归，在修改前跳高分别只有约 0.66m / 0.73m，没有达到正常跳高；某些接触姿态可在第一步被取消。

修复后只在真实控制器碰撞包含明显向下的障碍法线（normal1.y<-0.5），且向上位移受阻时清零上升速度；落地归零逻辑保持。未忽略碰撞或修改允许位移。开发实际顶墙起跳 desired.y=0.11111111、allowed.y≈0.11108589（差约 25μm），仍保留 velocityY≈6.66667，随后到 y≈2.07509。旧条件会把这样的侧向修正当作碰顶。

上坡表现符合当前参数，按用户授权保留。5m/s 水平速度、7m/s 竖直起跳、20m/s² 向下重力，在向上倾斜的地面上会较快重新接近坡面。45° 坡的初始法向离坡速度为 (7-5)/√2≈1.414m/s，法向重力约 14.142m/s²，连续理想峰值约 7cm；60Hz 离散模拟实测额外法向离坡间距约 5.89cm。30° 实测约 33.72cm。该间距是胶囊与坡面的法向距离增量，不是人物相对世界原点的竖直升高。仍然发生离地，起跳速度正确、起跳时吸附关闭。松开方向键在坡上站稳再跳，离地感会明显更强。

未增加坡面额外向上/向外速度，也未更改速度、重力或坡度限制。这里是对当前移动模型的判断，不承诺符合所有游戏的期望手感。
