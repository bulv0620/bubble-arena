## 版本兼容与问题处理

核对 registry：R3F 9.8.1 要求 React/React DOM >=19 <19.4、Three >=0.156；当前 React 19.3.0 满足。原生移动平台 peer 标记 optional，不安装 Expo/React Native。[R3F 官方安装说明](https://r3f.docs.pmnd.rs/getting-started/installation) 说明 React 19 与 Fiber 9 配对；[Canvas 文档](https://r3f.docs.pmnd.rs/api/canvas) 提供 fallback、DPR 和 demand 配置。

初始 Three 0.186.1 在浏览器出现 THREE.Clock 弃用警告；检查实际 R3F 源码仍调用 new THREE.Clock。改为经实际验证的 Three/types 0.182.0（[对应 Clock 源码](https://raw.githubusercontent.com/mrdoob/three.js/r182/src/core/Clock.js)），并重启 Vite 刷新优化依赖。最终开发和生产页面 error/warn 日志均为空。没有屏蔽 console 警告或改第三方源码。
