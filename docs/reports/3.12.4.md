# 3.12.4 换弹准星进度环与训练靶自动恢复

2026-10-09，implemented，待人工手感/视觉验收。阶段3共16项implemented，未进入阶段4玩家生命状态机。

换弹：RifleFireState.getReloadProgress直接返回最后处理物理tick的完成比例；未换弹/已完成为null，开始0，中点0.5，120步截止隐藏。LocalRifle单独进度订阅，Ammo HUD仍只在扣弹/开始/结束通知。88px青绿进度环包围64/52px准星，自12点顺时针填充，附实际剩余秒数与无障碍progressbar，不用CSS时长猜测。Esc释放输入时已接受换弹继续，准星按旧规则隐藏，独立进度环保持显示至完成。满匣/零备弹不显示环；重复R不重启换弹。

训练靶：shared配置restoreDuration=2s（version3），核心向上取整为120个60Hz步骤；致命命中后开始，每靶useBeforePhysicsStep推进，120步后恢复maxHp。等待中不扣血/不发浮字/不延迟恢复。累计命中数和lastHitTick保留、lastDamage清零；去重序号和接收tick跨恢复保留，等待中拒绝的有效身份也被消费，旧射击不能复活后重放。恢复时清空旧浮字，只通知恢复状态，不重播命中标记。头顶显示2s恢复，顶栏改为当前待恢复数。无新碰撞体/计时器或服务端玩法；本地规则未来由服务端运行。时间按模拟步计算，后台暂停/掉帧时不保证墙钟正好2秒。

文件：shared/trainingTarget；game-core/rifleFireState、trainingTargetState与reload/restore测试；web LocalRifle、LocalTrainingTarget、TrainingTarget及适配器测试；HUD/ReloadProgress、OverheadHealth、TrainingTargetHint、gameHud.css；BasicScene；任务、spec、状态与本报告。
