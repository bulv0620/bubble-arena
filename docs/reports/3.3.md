# 3.3 采集开火输入

2026-10-09，implemented，桌面锁定/真人组合试玩待验证。前置 3.2 implemented，阶段 2 accepted。当前只收集意图，未实现射速/扣弹/射击。

## 改动

- shared/src/input.ts、index.ts：只读 FireIntent，held 为持按，pressed 为合并的按下沿。无坐标/伤害/弹药。
- weapons/FireInput.ts、index.ts：确认本画布锁定后接受左键；首次申请锁定点击忽略。短点击松开后保留 pressed，consume 返回当前意图并只清除沿，held 持续至正常松键；多个短点击在读取前合并为一个沿，无无限队列。clear 清除沿与持按，不能靠轮询自动恢复。
- 对 Esc/失焦/隐藏/外部失锁/卸载清理；丢失 mouseup 时 buttons=0 停止 held，但保留真正短点击沿；修饰键、其他元素锁定、画布外事件与隐藏页面拒绝。
- 后备锁定失败/不支持时仅在右键瞄准期间收集左键；普通左键拖动不误开火。结束后备瞄准取消全部意图。仍锁定时松右键不取消腰射意图。
- core/BasicScene.tsx、camera/FollowCamera.tsx：最小装配与清空回调，attach 配对释放；瞄准后备时禁用左键拖动。PointerLockInput 增加默认兼容的 canRequest 钩子，瞄准后备左键不重试锁定，以免清掉短点击；松右键后明确点击仍可重试。
- weapons/FireInputHint.tsx：低频“未按下/按住/单击待处理”提示和后备说明，便于本任务复现；没有物理 tick、定时器或弹药状态。当前尚无消费方，待处理沿会留到 consume 或取消，3.4 再消费。
- FireInput.test.ts：12 项事件组合测试覆盖确认锁定、短点击/重复沿/持按、修饰键/隐藏/其他锁定、失焦/Esc/失锁、后备拖动保护与释放 click 不重试、重绑/旧清理/取消订阅。
- 任务卡补充必要的 core/camera 接线与请求互斥范围；状态/索引/README/模块说明同步。

## 试玩与交接

1. 桌面 Chrome 正常点击锁定，这个激活点击不产生意图；然后左键单击应显示待处理沿，按住显示“按住”、松开停止 held。
2. Esc/切换窗口/隐藏/外部失锁应清掉 pending 与 held，回来不自动触发。
3. 内置后备：普通左键拖动仍转镜头且无开火；先保持右键瞄准，再左键单击/按住采集，期间左键不拖镜头、不重试锁定。松右键取消后备开火；要调整镜头先松右键再拖动。
4. consume 用于后续固定 tick 获取意图；当前不消费弹药/产生有效射击，不能把一条客户端意图视为服务端伤害。

当前仅接口类型，尚无网络消息解析；后续网络任务需验证消息。没有射速、枪口、命中、弹药或换弹实现，不扩展 3.4。正式模型/MCP 状态保持。
