# 3.2 装备步枪占位模型

2026-10-09，implemented，待用户视觉验收。前置 3.1 implemented；阶段 2 accepted（stage-2-accepted）。

## 实现与边界

- apps/web/src/weapons/RiflePlaceholder.tsx、index.ts：工程白盒枪由枪身、枪托、握把、枪管、前端五个声明式 mesh 组成；颜色/尺寸在单个组件定义。
- player/CapsulePlayer.tsx：在现有 visual group 下挂 RiflePlaceholder，不新建 Rigidbody/Collider；自动继承角色位置、跳跃和实际/瞄准 yaw，UI 不管理物理步。
- weapon_socket 在胶囊中心右侧 x=radius+0.1m、y=0.2m、z=-0.08m；枪使用资产标准局部 +Z，socket 绕 Y 旋转 π 适配已验收白盒角色 -Z 前向。模型无世界位置拷贝逻辑，不改控制器朝向。
- 几何体/材质通过 R3F JSX 创建和卸载释放；无全局资源、加载请求、手工缓存、监听器或定时器。
- 任务卡补充必要的 CapsulePlayer 最小视觉接线范围；README、模块说明、任务状态/索引、STATUS 与本报告更新。
