# 任务 2.5 鼠标锁定与释放

2026-10-08，implemented，待人工手感验收。用户授权整批 2.5～2.7；本项前置 2.4.3 implemented，验证后继续 2.6。

PointerLockInput.ts 拥有 canvas 点击请求、document change/error 确认、相对 movementX/Y 输入和低频状态订阅。Esc、失焦、隐藏页、外部失锁、卸载清空移动/跳跃并释放自己拥有的锁；不抢占其他元素的锁。请求重复抑制，兼容同步异常、Promise 拒绝及旧式 void 返回；取消/卸载后晚到的授权立即释放。旧式未完成请求仅保留 settlement 监听至事件完成，以免遗留锁；不自动重新锁定。

PointerLockHint.tsx 显示 idle/requesting/locked/error/unsupported；FollowCamera.tsx 绑定锁定输入，MouseOrbit.ts 的拖动仅在 error/unsupported 启用，避免双重旋转。BasicScene.tsx 装配控件和 input.clear，任务卡补充范围。鼠标未锁定时 WASD 仍可试玩；Esc/失锁会清空当时持有/排队的输入，不暂停物理。

PointerLockInput.test.ts 新增 6 项确认/拒绝/释放/失焦/隐藏/外部失锁/晚授权/重新绑定/订阅清理路径测试；MouseOrbit.test.ts 增加后备与锁定互斥测试。pnpm check 全通过：16 文件 124 测试、typecheck/lint/build/工作区索引。后备加入前 123 测试也通过，最终以 124 为准。

实际 Chrome 新开本地游戏标签页，点击画布后显示“鼠标已锁定”和浏览器 Esc 通知；按 Escape 回到点击锁定提示，截图 chrome-locked.png/chrome-released.png。内置浏览器实际拒绝锁定，不声称已成功；失败提示下实际左键拖动旋转成功，iab-denied.png/iab-fallback.png。失焦/隐藏/晚授权通过模拟事件测试覆盖，未声称实际浏览器切出验证。[证据目录](../../tests/manual/2.5/)。请求成功/失败按 document 事件确认，兼容处理依据 [MDN requestPointerLock 文档](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestPointerLock)。

没有新依赖、付费服务或物理 tick/坐标修改。既有构建大包/Rapier 提示保留；锁定支持取决于宿主浏览器，内置浏览器应使用后备或 Chrome。本项本地提交 feat: add pointer lock controls and drag fallback，未推送。之后继续已授权的 2.6。

整批收尾补充：新增旧画布请求晚授权、同时已切换到另一个不支持锁定的画布路径；仅新绑定在同一画布且明确 requesting/locked 时允许接管旧授权，其他晚授权释放。该回归通过，批次最终 17 文件 140 测试；补充随本批最后提交保存。Chrome 后续被用户切换，未继续操作其当前页面；最终整体验证在内置浏览器后备模式完成。
