## 手动复现

1. 仓库根目录 pnpm install --frozen-lockfile。
2. pnpm dev，打开 http://localhost:5173，应看到 Bubble Arena 和“阶段 0 · 工程初始化”，刷新后内容保持正常。
3. pnpm typecheck、pnpm build；运行 pnpm preview，打开 http://localhost:4173，确认同样页面。

开发进程在本次交付时保留以便查看；生产预览验证后停止。未来会话若未运行，重新 pnpm dev 即可。
