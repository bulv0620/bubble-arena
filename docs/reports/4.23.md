# 4.23 狙击开镜鼠标速度倍率

2026-10-17。implemented，待人工手感验收。用户要求开镜速度可独立调整，作为普通鼠标速度的倍数，并降低默认速度。

## 实现

Esc设置新增“开镜速度倍率”，0.05～2.00、步长0.01、默认0.30。实际yaw/pitch增量=鼠标增量×基础灵敏度0.003×普通速度×开镜倍率。只在LocalLoadout实际scoped时乘倍率，射后收镜、关镜、切枪等自动恢复普通速度；不叠加FOV比例、不引入角度追赶。

普通鼠标速度和开镜倍率分别校验，因此最低组合0.05×0.05=0.0025仍可正常转动。锁鼠标及不支持锁定时的左键拖镜头使用同源倍率；修正后备拖镜头开镜期间被旧aim门禁禁用的问题。设置修改通过Ref即时供输入读取，不重新绑定监听器。原释放、失焦、隐藏、卸载、菜单门禁沿用。

独立本地键`bubble-arena.scope-mouse-multiplier.v1`，不覆盖普通鼠标/HUD设置；缺失、空值、非法值、存储不可用均容错。设置仅三滑杆及退出游戏/返回游戏两个按钮，无新增提示区域。
