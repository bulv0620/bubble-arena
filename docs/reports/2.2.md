# 任务 2.2 鼠标旋转镜头

2026-10-08，implemented，待人工视觉/手感验收。本次仅执行 2.2，前置 2.1 implemented，阶段 1 accepted。

## 实现与文件

- packages/shared/src/camera.ts：灵敏度 0.003 rad/像素、旋转响应 14/s、临时极点保护 ±89°。正式范围 -60°～70° 属于 2.3；鼠标锁定属于 2.5。
- apps/web/src/camera/MouseOrbit.ts：表现层独立角度与输入类，左键须在画布按下才能拖动；全窗口接收移动与松键。非左键、修饰键按下或隐藏页不启动；丢失按键、mouseup、blur、隐藏页清除拖动。detach 幂等，重新绑定释放旧监听，旧清理不影响新绑定。
- 指数响应使用实际渲染 dt，30/60Hz 等时间响应一致；yaw 环绕最短路径跨 ±π，pitch 保持极点内。非法输入/dt 忽略。松键后已输入角度完成平滑收敛，不继续增加目标角度。
- cameraFollowPose.ts：肩部观察点随 yaw 旋转，球面偏移保持距观察点 4.5m，以世界 Y 为上；只读目标，位置/角度非法或目标缺失保留上一相机姿态。
- FollowCamera.tsx：组件 effect 配对绑定/释放画布事件；渲染帧更新镜头，无 React 每帧状态、无额外定时器，不参与物理 tick。开发日志增加实际 yaw/pitch 与旋转后距离。
- core/BasicScene.tsx：仅装配生产可见操作提示，范围已在任务卡补充。
- MouseOrbit.test.ts、cameraFollowPose.test.ts：新增 5 项正常/边界/生命周期行为测试；其他物理/输入代码未改。README、共享参数说明、模块边界、任务卡/注册表/索引、STATUS 和本报告同步。
