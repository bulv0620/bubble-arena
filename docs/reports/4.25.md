# 4.25 枪械恢复固定朝前持枪姿态

2026-10-17。状态：implemented，待人工视觉验收。用户澄清此前“枪口朝准星”是静态视觉持枪，枪身仍跟身体朝前，不追踪命中物体或靠墙上扬。

## 结果

四把ToyWeapon固定相对身体位置和旋转[0,π,0]，移除朝目标的逐帧俯仰/偏航和视觉aimTarget参数。枪身只跟身体水平朝向，镜头俯仰、目标远近、近墙均不修改相对姿态；现有持枪高度/枪型长度、相机和形体保持。

逻辑枪口按身体中心/yaw/枪型长度从固定模型配置推导，与真实muzzle节点一致，闪光仍跟该节点的位置和方向。实际弹道独立从此枪口朝准星世界点计算，再加现有散布；不把固定枪管轴线当实际弹道。目标在枪口后方或沿相机前向投影≤0.05m时使用相机前向后备，重合/非法输入拒绝，避免倒射；身体至实际枪口地图安全段仍先查询。伤害、穿透、武器节奏、开镜速度倍率及移动响应保持。
