2026-10-08，implemented。仅创建物理世界，1.3 未执行。

## 实现

- core/PhysicsWorld.tsx：Physics timeStep=共享 1/60，重力 [0,-20,0]，updateLoop=independent，colliders=false、interpolate=false。
- BasicScene 用 Suspense 等待 WASM，并在 Physics 中装配已有视觉地图。无 RigidBody/Collider/玩家。
- packages/shared 建立 workspace 包和纯配置入口；web 用 workspace:* 引用。未新增第三方版本，lockfile 记录本地包连接。
- 开发诊断只采集最初 60 次 useAfterPhysicsStep 的真实 timestep，输出 min/max 和实体数量，不通过 React state 每 tick 重渲染；生产版不输出此诊断。

[Physics 官方配置说明](https://pmndrs.github.io/react-three-rapier/interfaces/PhysicsProps.html) 中 independent 适用于按需渲染；实际安装源码确认数值 timeStep 使用累加器分步模拟。浏览器 rAF 在后台会节流，这里保证固定模拟 dt，不承诺墙钟回调频率或两端完全确定性。

共享 TS 源包由 Vite/Vitest 编译；未来 Node 20 服务端仍需 TS loader/构建，不声称已提供 JS 发布产物。
