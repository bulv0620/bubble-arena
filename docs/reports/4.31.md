# 4.31 参考资料与统一瞄准系统

2026-10-18。implemented，待用户玩法/视觉验收。用户授权查阅泡泡战士、PUBG后直接决定实现，不再请求方案选择。现行唯一规则见[WEAPON_AIM](../spec/WEAPON_AIM.md)。

## 查证结论与采用方案

[Nexon提供、Inven刊载的早期官方介绍](https://www.inven.co.kr/webzine/news/?news=16740)明确雷达区域具有辅助锁定作用，且随武器变化；它不能直接当作纯散布圈。查看了其中[实机截图](https://img.inven.co.kr/column/jukz_inven_game_story/%2874%2920080721153914636.jpg)。[Nexon官方片](https://www.youtube.com/watch?v=dBiWDSwu5ao)实际播放后为宣传动画，未据此推断射线代码。资料日期为2008/2015，不声明适用于原作所有后续版本。

[PUBG 33.1官方说明](https://pubg.com/en/news/7988?category=patch_notes)确认腰射/肩射有初始与持续开火散布，移动精度另行调整。[官方弹道支持说明](https://support.pubg.com/hc/en-us/articles/115004202434-How-are-the-ballistics-applied)确认远程下坠与归零补偿。来源并未公开两款游戏的底层射线算法，以下是本项目工程选择，不声称照搬原作源码。

采用手动TPS双射线：每丸相机锥内采样并选择可见地图/目标点，再从真实枪口向该点发射。实际地图、人物、困泡、穿透、曳光和泡泡飞行都沿真实枪口路径；没有相机虚拟伤害起点或泡泡视觉位移修正。正常零散布可达目标对齐准星；遮挡时允许先撞掩体，并给挡枪反馈，避免一边显示枪口发射、一边从旁边的准星线扣血。

保留既有手动部位瞄准、枪械数值、移动/跳跃惩罚、连射扩散和后坐力，不加入雷达自动锁定或远程重力/归零。三枪仍瞬时判定+短曳光，泡泡仍20m/s真实飞行；狙击无衰减/头击致命、霰弹2发快节奏及救援UI等原功能保持。

## 文件与实现

- `apps/web/src/weapons/muzzleRay.ts`：相机选点→真实枪口方向→真实地图交点。保留身体到枪口安全段，近后方点不得反向射击。新增只读aimObstructed反馈；枪口提前命中掩体仍保留真实hit供穿透/效果消费，不虚构摄像机命中。
- `RifleSimulation.tsx`：散布改为在相机锥里逐丸采样，再通过TrainingTargets选点，最后走同一枪口查询。接受时的瞄准事实与扩散角保持先于本发后坐力。四枪共用；原样本数和分布不变。
- `LocalBubbleFlight.ts`、`BubbleVisuals.tsx`：移除4.30虚拟起点及0.1秒展示偏移映射；flight与显示直接共用真实枪口起点和位置，没有新增对象寿命。
- `HUD/crosshairSize.ts`、`useReticleSize.ts`：外圈按实际锥角、FOV、窗口高度投影并加可读留白，36px起始，不再统一112px封顶；resize订阅成对释放。准星仍不随HUD缩放改变。
- `Crosshair.tsx`、`ReloadProgress.tsx`、`player/CapsulePlayer.tsx`：中心点/描边固定像素，进度环和自身血条避让使用同源尺寸，身体中心保护仍26px。
- `aimAlignment.integration.test.ts`、`muzzleRay.test.ts`、`weaponAimPose.test.ts`、`HUD/crosshairSize.test.ts`：更新现行物理路径与投影断言，补齐遮挡/泡泡/霰弹与固定中心偏移回归。
- README、web架构说明、STATUS、任务/索引、WEAPON_AIM、CAMERA_FRAMING、SHOT_EFFECTS、COMBAT_HUD、TEST_FEEDBACK_BATCH统一基线；历史4.25～4.30报告仍保留。

无新增依赖或正式模型，无无关重构；此前工作区改动保留。AI现有真实枪口/自主瞄准不改。

2. 实际静止步枪首发0.2°，有效随机输入覆盖中心至近外沿，1280×720样本偏移<2.1px；开镜首发0°真实小头部sensor伤害与射后关镜/后坐力事实隔离。

4. 相机看见但枪口被挡时真实撞掩体且不扣后方目标血；枪口落在墙内，即使选点与枪口重合也不得绕射；镜头选到身后点拒绝反射。
5. 相机选中远处头部，但枪口真实路径先碰困泡时，困泡截断且后方不受伤；既有队友球/木箱/人物穿透由全套回归覆盖。
6. 泡泡从物理枪口连续飞行，位置与方向同碰撞，清理沿用；外圈随画幅/FOV变化且实际霰弹锥不会被旧112px上限截断。

测试中纠正了旧首发样本用radial=1的非法边界：采样接口约定[0,1)，现在用0.999999并显式检查采样成功，不再让null样本落回默认方向造成假验证。

## 试玩与边界

刷新5173或4173后，近远距离静止单点/开镜单点检查瞄准中心；转到墙边，看到挡枪符号时射击应先打墙，不会从相机旁穿过去。移动、跳跃、连射时外圈扩大；停火后收回。霰弹有8条短轨迹，泡泡从枪口连续飞行，均与碰撞位置一致。换弹/冷却只有一个外围环。Esc退出、再进入验证输入/Canvas与飞行对象释放。
