- apps/web/src/input/AimInput.ts、AimHint.tsx、index.ts：右键仅在画布进入，按住不重复通知、全局松键退出；Esc、失焦、隐藏、失锁、锁定错误、鼠标 buttons 丢失和卸载取消。重绑、重复释放、旧清理不会伤害新监听；画布抑制右键菜单。未锁定或锁定失败时也可试玩。

## 试玩步骤与限制

1. 打开 http://localhost:4173/，按住画布右键：右上显示“瞄准中”，镜头向右肩调整并拉近、视野缩窄。
2. 松开右键：提示恢复普通，FOV/肩偏移即时恢复，距离稍后平滑放远；多次快速重复不粘住。
3. 点击锁定鼠标（内置拒绝时可用后备）；持右键移动鼠标、WASD、跳跃并贴墙查看，镜头仍避障。持键按 Esc、切换窗口或隐藏页面应退出，回来不会自动举枪。
4. 当前只有瞄准状态和镜头，无枪械模型/举枪动画/射击；角色依旧随实际移动转向，瞄准朝向留到 2.9。当前移动速度仍 5m/s。正式模型仍需 Blender MCP B.1，本轮未调用或替代。

没有准星、狙击开镜、瞄准过渡动画。极近镜头裁切、肩位即时切换和既有首帧现象保留供后续试玩；地图 hash 与 8 实体保持。人工验收前不标 accepted、不关闭阶段 2。
