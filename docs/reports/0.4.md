## 兼容依据

实际查询 registry：Drei 要求 React/DOM ^19、Fiber ^9、Three >=0.159；React Rapier 要求 React ^19、Fiber ^9.0.4、Three >=0.159。现有 React 19.3.0、Fiber 9.8.1、Three 0.182.0 满足。

[React Rapier 官方说明](https://github.com/pmndrs/react-three-rapier) 说明 v2 支持 React 19 / Fiber 9；[Drei 官方仓库](https://github.com/pmndrs/drei) 为辅助库来源。

React Rapier 2.2.0 内部精确依赖 compat 0.19.2，因此直接依赖也采用 0.19.2，没有引入不一致的最新 0.21.0。pnpm why 验证这两条运行路径都为 0.19.2。@types/three 内部另带 compat 0.12.0，属于其类型声明依赖；没有强行全局覆盖它，后续模拟模块必须从显式 0.19.2 入口导入。
