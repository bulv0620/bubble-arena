# 4.24 提升移动起停和变向响应

2026-10-17。状态：implemented，待人工手感验收。用户要求移动更跟手、运动更灵活。

## 结果与参数

仅调整既有共享移动参数，沿用固定步意图和Rapier角色控制器。

| 项目 | 调整前 | 调整后 |
| --- | --- | --- |
| 加速度 | 30m/s² | 90m/s² |
| 松键减速度 | 36m/s² | 120m/s² |
| 空中加减速系数 | 0.35 | 0.65 |
| 步枪地面起步到6m/s | 12tick/200ms | 4tick/约67ms |
| 步枪地面松键停步 | 10tick/约167ms | 3tick/50ms |
| 松键后累计水平滑行 | 约45cm | 约10cm |
| 地面满速同轴反向 | 24tick/400ms | 8tick/约133ms |
| 空中满速同轴反向 | 69tick/1150ms | 13tick/约217ms |

90°地面转向约6tick/100ms。以上为无遮挡固定60Hz速度响应，不代表鼠标/键盘到显示器的端到端延迟。普通最高速度仍步枪6、轻枪6.6、狙击4.8m/s，重量、奔跑1.35倍、开镜0.7倍保持；跳跃/重力/地形限制及困泡/救援/比赛门禁保持。对角不加速，不新增冲刺、滑铲或其他动作。

- `apps/web/src/maps/whiteboxCollision.test.ts`：平台顶面检查改为在到达平台中心时采样；快速起步后原固定35tick已走出2m平台，并非无法上台阶。
- `packages/shared/README.md`：更新当前物理参数表（包括4.20速度和4.22形体）。README、STATUS、任务/索引和TEST_FEEDBACK_BATCH同步。

原停步测试把垂直浮点接触分离也计为水平滑行；诊断实测松键后X/Z漂移约0.003mm/0.009mm，Y分离在0.658156→0.660098m间回落地间隙，差约1.942mm。改为水平仍严格小于1mm、垂直接触分离小于3mm，并验证最终落地高度。地图每tick法向不穿透1mm约束、墙/台阶/坡/跳跃检查保持。临时诊断日志已移除。
