# 4.26 救援与踢泡互斥、延时击破及水球挡弹

2026-10-17。implemented，待人工玩法/视觉验收。用户授权本卡六项修改，覆盖4.18.3瞬时踢破及4.19水球按人物穿透的旧规则。

## 最终行为

1. E踢敌方水球改18tick/0.3秒承诺动作，允许行走中触发；行动开始后锁移动、跳跃、奔跑和武器操作，松E不提前完成，保留镜头观察。正式踢动画未制作，B.3记录后续clip合同。
2. 行动不新增无敌。期间正常受伤，非致命伤可继续；被击倒/淘汰立即失败。本tick全部伤害之后才复核并完成，完成步中被打倒也不能踢破。目标恢复/被打破/身份变化、离开距离/地图视线、菜单/失焦或结束也释放。仅成功完成才爆泡/计分。
3. 倒地后整个半径1.12m球壳是body命中面，外缘未碰人模型也扣敌方隐藏300耐久，无爆头加成或隐藏耐久浮字/条。
4. 水球独立为bubble射线接触，任意枪都停在球面，狙击亦不可穿。友方水球同样挡弹但免伤，正常友军人物仍通过。每颗霰弹独立，普通人/木箱原穿透参数保持；若球已消失，后续射击可通过。泡泡投射物仍碰球爆开，现有范围效果保持。
5. 救援和踢破共用一个目标占用表，目标只能同时接受一人的E交互；现有持有者优先，同tick新候选按稳定playerId。保持一人一目标、生命身份复核、伤害先结算和完成去重。普通子弹伤害不占用E动作通道。
6. 公共救援进度随目标水球，球心+球半径+0.25m锚点；红蓝双方、本机操作者/被救者均可见，与本机选中目标无关。保持正常地图遮挡/屏外隐藏/透视缩放，完成/中断移除。底部只显示交互文字。

AI沿用同一进度/占用/完成规则，动作期间maxSpeed=0且禁射。菜单只取消本机通道，不误清其他AI救援。当前仍本地权威模拟，未实现联机广播。
