# 3.8 创建带生命值靶子

日期：2026-10-09。状态implemented，待人工试玩验收。前置3.7已实现；阶段2已验收。

## 结果与3.9边界

新增青色工程练习靶，默认100HP，HUD显示HP与受击次数。TrainingTargetState.receiveHit是独立受击接口，校验tick/sequence，保持不可变状态、记录一次受击；3.8不扣血、不闪烁、不播命中音，伤害与反馈由3.9实现。不实现玩家倒地/复活或联机权威生命。

TrainingTarget共享配置version1，位置[-1.45,1.35,-1.6]，视觉与sensor胶囊共用PLAYER尺寸；属于独立测试夹具，非正式Blender角色/地图。独立trainingTarget/targetQuery碰撞组：移动/镜头静态地图查询忽略它，无推动碰撞，白盒地图数据/hash不变。

TrainingTargets维护注册handle→接收器；准星从地图遮挡范围内选最近注册靶子。接受开火完成固定物理步后，先用3.7安全段/地图枪口射线限制，再查询最近靶子并调用独立receiveHit。枪口受阻、射程外、无目标、未注册、重复/过期射击不触发。地图与目标同面时用1e-5m保守余量优先地图，避免浮点边界穿透。未命中事件也消耗射击身份，不能在后来目标移动后重放。

注册/清理由组件effect返回函数管理，重复清理及旧清理安全；R3F移除sensor/body，不手工free已由框架管理的对象。LocalTrainingTarget仅在接受受击后通知，HUD无帧计时器或物理循环，刷新整个场景重置靶子与步枪。当前仅单机单步枪会话身份；未来服务器独立确认命中并提供全局事件身份，不信任客户端坐标/伤害。

## 试玩与限制

1. pnpm dev或pnpm preview打开场景，青色练习靶和右上100/100、受击0显示。
2. 初始镜头已经指向靶子上部；点击画布锁定，再左键射击。受击次数每次有效开火增加一次，弹药扣一发，HP本项仍100。
3. 移动/转向使准星偏离、躲到墙后或枪口受阻，开火仍扣弹，受击计数不增加。
4. 换弹/空弹/冷却无新受击；刷新场景恢复初始。内置拒绝锁定时，沿用右键瞄准+左键射击后备。
5. 靶子无实体阻挡，可走过；正式角色模型/击倒规则不在本项。开发红点和shotRay保留地图界限，黄色目标可落在靶子；不要把地图红点解释成靶子反馈，3.9将统一伤害表现。
