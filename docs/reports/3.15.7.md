# 3.15.7 泡泡命中后靶子血条遮挡修复

2026-10-10用户报告偶发泡泡命中后血条消失，并补充确认是靶子头顶条。前置3.14.4/3.15.6已实现。本项implemented，待用户重试偶发场景确认；阶段3共36项implemented，未关闭，不进入阶段4。

## 复现机制与修复

TargetOverheadHealth使用Drei Html occlude全场景射线。检查本机Three0.182.0发现Raycaster递归不按visible过滤；BubbleVisuals爆炸球在0.3秒内扩张至接近2.2m，结束仅设visible=false，位置/几何/scale仍留在固定池内。回归用与场景一致的中靶锚点、相机和透明线框球实测：可见或已隐藏的扩张球均在血条锚点之前被射线命中，足以让Html设display:none。这是被复现的具体遮挡路径；未声称捕获了用户原始浏览器操作。

本机Drei10.7.9的遮挡判断仅在投影位置/zoom变化超过eps时更新，因而镜头/后坐力移动与扩大特效相遇的时序可能形成偶发隐藏；这是代码推断，不虚报逐帧现场日志。更关键的是隐藏球仍可命中，所以仅等待特效结束不足以移除这条遮挡路径。

新增effects/skipEffectRaycast.ts，group射线回调返回false，使Three在纯特效池边界停止递归。BubbleVisuals和ShotEffects在各自根group应用：飞行/爆炸以及枪口/冲击/霰弹轨迹都不参与Html遮挡与指针命中。没有取消TargetOverheadHealth的occlude，真实墙体/场景仍可挡住血条。渲染、固定容量/释放、Rapier扫掠、范围伤害/减速、靶子恢复算法不变，无新增计时器/物理体/依赖。
