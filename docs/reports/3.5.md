# 3.5 换弹状态机

日期：2026-10-09。状态 implemented，待人工玩法验收。前置3.4已实现，阶段2已验收。

## 实现

步枪 R 换弹按共享2s配置，以已有60Hz物理步推进；开始 tick +120 完成，开始和完成 tick 均禁止射击。持续按住左键在完成后的下一tick可恢复，短点击不积压。R与同tick开火同时出现时有效换弹优先。重复R不重启，满弹匣/无备弹忽略，无自动换弹。完成时原子转入 min(缺弹量,备弹)，不扣多余备弹。

ReloadInput采集布尔按下沿，忽略键盘重复、文字输入、修饰键、输入法组合和隐藏页面；R与移动一样可在未锁定时使用。Esc/失焦/隐藏/编辑区焦点/卸载清空未消费输入，已开始换弹继续，不添加UI计时器。物理停止时不会用墙钟追补。倒地取消和复活重置在生命阶段实现。

LocalRifle订阅只在扣弹或换弹开始/结束更新；快照冻结，HUD显示共享耗时。core无DOM/React/传输依赖，未来服务器独立执行同一规则，客户端意图不具有伤害/坐标/弹药权威。

## 人工试玩

1. pnpm dev，点击画布锁定，再单击/按左键扣弹，松开。
2. R：显示换弹中，期间按左键/R不扣弹不重启；约2秒结束，按缺弹量扣备弹。
3. 持按左键跨越换弹，完成后自动恢复连射。短点击在换弹期间只被忽略。
4. 满匣R不启动。逐轮耗尽备弹后R无效，弹药不负数；无自动换弹。
5. R快速按下/松开仍触发一次；按住R不自动重复。Esc/失焦清空输入，已接受换弹完成。刷新整个场景恢复30/120。
