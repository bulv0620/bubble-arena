## 修改与规则

- packages/shared/src/weapons.ts：WeaponId 为 rifle/shotgun/sniper/bubble 联合类型；只读 WeaponConfig 定义 id、damage、fireRate、magazineSize、reserveAmmo、range、reloadDuration。fireRate 单位次/秒，range 米，reloadDuration 秒；与当前 GAME_DESIGN 数值一致。
- parseWeaponConfig(unknown)：仅接受纯数据对象，严格校验所有必需且仅声明字段、合法 ID、正有限伤害/射速/射程/换弹时长、正安全整数弹匣和非负安全整数备弹。不转换字符串或布尔值；拒绝数组/访问器/特殊原型/符号额外字段，错误抛 TypeError；返回独立冻结副本。
- WEAPON_IDS 和 WEAPON_CONFIGS 冻结，四武器基础初值集中定义。霰弹 damage=8 表示单粒，不表示整次 64 伤害；散射/投射物/后坐力/开火策略等机制未实现。配置非可变弹药状态，也不授予客户端有效伤害。
- shared/src/index.ts 公开导出；weapons.test.ts 验证正常配置、未知值、异常路径、冻结和源对象隔离；tests/tooling/weaponSchema.types.ts 通过 TypeScript 负例断言未知 ID、错误字段类型、必需字段和 readonly。
- 任务状态/索引、STATUS、README 与 Shared 文档同步。阶段 2 任务卡状态文字与 accepted 对齐，历史报告的实现检查保留。

## 复现与限制

执行 pnpm check。可经 shared 公共入口 parseWeaponConfig 读取未知 JSON，非法值抛 TypeError，合法值返回 WeaponConfig 冻结副本；WEAPON_CONFIGS.rifle 可供后续规则使用。TypeScript 的 number 本身不限制正负/有限值，所以外部或动态配置必须经过运行时解析；客户端不应发送配置改写服务端规则。当前还没有网络协议或服务器接入。
