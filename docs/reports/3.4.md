# 3.4 射速与弹药状态

2026-10-09，implemented，持续扣弹真人试玩待验证。前置 3.3 implemented，阶段 2 accepted。本轮仅接入步枪状态，不实现 3.5 换弹或弹道/命中。

## 文件与行为

- game-core/rifleFireState.ts、index.ts：RifleFireState 每次 step 对应 PHYSICS_CONFIG 60Hz 一 tick，只接受 boolean held/pressed 意图；冷却到期且弹匣有弹时返回不可变 tick/sequence，弹匣减一、备弹保持，其他情况 null。状态冻结，独立实例互不影响。
- 构造用共享 parseWeaponConfig 校验，只接 rifle，射速不超过 tickRate，派生周期必须有限；初值采用共享 30/120、8/s。无 DOM/React/网络或真实时间来源，坏意图在推进 tick/扣弹前拒绝。
- 8/s 周期为 7.5 tick，连续相位落于 0/8/15/23/30/38/45/53，60 次 fixed step 接受 8 次；每次不早于计划时刻，量化延迟 <1 tick。相邻实际执行间隔 7 或 8 tick，而非声称每次毫秒间隔精确相同。空闲后重新建立相位，无补射积压，每 tick 最多一次。
- 松键只停止新的持按射击，不重置现存冷却；冷却期短点击拒绝，不延后自动触发；空弹不下溢/不自动吃备弹，累计最多 30 次。现无重置/换弹入口，刷新整个场景恢复初值。
- web/weapons/LocalRifle.ts、RifleSimulation.tsx、index.ts：使用现有 Rapier useBeforePhysicsStep 注册固定物理回调，消费 FireInput 后调用共享规则；只在接受时发布快照，开发模式记录 weapon.check。无新 timer、useFrame 射击或额外物理 tick。
- HUD/AmmoHint.tsx、index.ts 与 core/BasicScene.tsx：最小装配，显示弹匣/备弹，空弹匣提示；React 只订阅改变，hook/订阅随卸载释放，不创建世界碰撞体或模型。
- rifleFireState.test.ts、LocalRifle.test.ts：11 项新增测试覆盖 8/s 相位、单击/持按/冷却、空弹/备弹、输入取消/重按、不追补、错误配置/意图、不可变/实例隔离、render 分组一致、订阅取消，以及实际输入采集器组合扣弹。任务卡补充最小 core 接线和量化语义。

## 试玩与限制

1. 解锁 Mac 后桌面 Chrome 打开 http://localhost:4173/，点击确认锁定。初次激活点击不扣弹；左键短击一次减少一发。
2. 持左键约 1 秒，弹匣按目标 8/s 递减；松键停止，快速点击不能跳过冷却。持续约 4 秒最多耗尽 30，显示空弹匣，备弹仍 120。
3. Esc/切换窗口/隐藏页/外部失锁取消意图，不应继续扣弹；重新激活不重置弹匣/冷却。刷新可重新测试。
4. 内置后备必须先进入锁定失败状态，再按住右键瞄准并左键触发；普通左键拖动不得扣弹。当前工具同时持按组合不稳定，需真人组合操作。

目前是单机规则执行，没有有效命中/伤害、子弹视觉、声音或换弹；接受开火返回值不是服务器有效伤害事件。未来权威服务器按同一 core 独立运行，客户端只提交意图。其他武器机制不在本轮。Blender/正式资产状态保持。
