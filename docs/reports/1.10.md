# 任务 1.10 实现报告

2026-10-08，implemented，待用户手感验收。配置并验证 45° 最大坡度与 0.3m 台阶；未执行 1.11。

## 实现与文件

- packages/shared/src/player.ts：maxSlopeAngle=π/4、maxStepHeight=0.3m；辅助初值 minStepWidth=0.4m、groundSnapDistance=0.3m，均集中共享。坡度边界容差 0.001 弧度（约 0.0573°），用于 float32 胶囊接触法线的误差，不将“数学上严格 45.000°”作为浮点承诺；45.1° 和 55° 均实测阻挡。
- apps/web/src/player/RapierMovement.ts：配置最大攀爬/最小滑落角、静态地图自动台阶。每 tick 先关闭吸附并探测当前接地，探测距离由 2cm / cos(45°) 得到约 2.83cm，覆盖斜面法向接触间隙。接地资格仍由 Rapier 坡度限制判定；碰撞法线只用于识别斜面并选择吸附。已接地、未向上跳跃且检测到斜面时启用吸附，下坡保持接地；平地和墙边不开启吸附。
- packages/shared/src/whitebox.ts：新增蓝色 0.3m 台阶（中心 x=3,z=6）和绿色 45° 坡（中心 x=6,z=-0.5，长 4m、厚 0.2m、宽 1.5m），高度/坡角取共享玩家参数。坡顶低端与地面齐平，部分底板在地下。新增 rotationZ；碰撞 schemaVersion=2，旋转进入规范化数据和哈希。
- apps/web/src/maps/WhiteboxMap.tsx：固定刚体旋转承载显式碰撞体和视觉盒，保持二者一致；仍为工程白盒，无正式模型。
- terrainMovement.test.ts、whiteboxCollision.test.ts、gravityJump.test.ts、shared/whitebox.test.ts：新增地形规则测试，旧全地图夹具加载真实旋转，增加旋转哈希/坡底检查。
- 更新 README、任务卡/注册表/索引、STATUS、本报告和 tests/manual/1.10 证据。无新增依赖，无镜头或输入规则变更，控制器沿用既有释放流程。

地图身份从 fnv1a64:f100071d20585698 更新为 fnv1a64:4abdb29633dc2d14；运行时包含地面、两墙、两箱、台阶、坡和玩家，共 8 刚体 / 8 碰撞体。

坡度、自动台阶和吸附使用本地安装的 Rapier 0.19.2 类型/API，并核对 [Rapier 官方控制器说明](https://rapier.rs/docs/user_guides/javascript/character_controller/)。在线说明当前标示 0.21；本项目未升级，实际可用接口以本地类型与真实测试为准。

## 实际检查与证据

完整 pnpm check 通过：工作区、类型、lint、10 文件 83 测试、生产构建。新增 11 测试，原 72 个均回归通过：

- 0.15 / 0.29 / 0.3m 台阶无需跳跃走上，停稳接地且可以跳跃。
- 0.4m 台阶阻挡；顶棚不足以容纳胶囊的台阶也阻挡。
- 30° / 45° 坡上行、停稳、下行通过；下坡仍在坡上时最多 1 个 tick 无接地反馈；所有步 contact.distance≥-1mm。
- 45.1° / 55° 坡不能靠持续水平输入爬上。
- 坡上起跳立即离地，空中反复请求无法再次起跳。
- 实际共享可见台阶和旋转坡的地图碰撞通行验证。

开发与生产浏览器均使用真实 WASD：D 从出生点走上右侧绿色坡，A 下坡，S 走上前方蓝色台阶；没有按 Space。开发实际日志：坡上停稳 x≈5.52794、y≈2.07220、grounded=true、velocityY=0；台阶停稳 x≈3.08991、z≈5.44886、y≈1.21010、grounded=true。物理日志确认 8/8 对象及新地图哈希。开发保存日志无 error，生产错误查询为空。

## 限制和下一步

全局吸附试验导致平地顶墙侧偏超出既有 1cm 阈值；改为仅斜面接地运动启用后原阈值通过，没有放宽旧测试。45° 精确边界出现接触法线误差，加入上述小角度容差并用 45.1° 阻挡测试约束。仍可能有微小浮点位置校正。

台阶往下离开平台仍由重力着陆；坡面吸附不会把跳跃中的角色拉回地面。当前只支持静态地图通行，未引入动态平台。没有联机、正式模型、跌落复活。正式模型仍需 Blender MCP B.1，白盒坡/台阶为工程测试几何。没有宣称用户已完成人工玩法验收或已修复既有偶发空画面问题。

本地 Git 快照 feat: configure slope and step traversal；未推送。下一任务 1.11 抽取参数配置，整理剩余速度、重力、跳跃、摩擦及加减速参数。
